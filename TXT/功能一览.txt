项目文件与文件夹功能一览

说明：按当前工作区整理。自动生成的虚拟环境、缓存和 Git 内部文件仅说明目录用途；本地密钥、数据库及工具个人配置不读取具体内容。

一、根目录文件
- .env：本机运行配置，通常包含数据库、模型 API 和认证密钥；仅供本地使用，不应提交。
- .env.example：环境变量模板，展示启动所需配置项和示例值。
- .gitignore：指定 Git 忽略的密钥文件、数据库、缓存、虚拟环境及前端构建产物。
- .mcp.json：MCP 客户端配置示例；未接入 MCP 时不参与现有聊天流程。
- app.py：兼容启动入口，保留旧的应用导入方式。
- dev_agent.db：本地 SQLite 数据库文件；运行数据文件，不是源码，内容不在本清单中读取。
- main.py：兼容旧导入方式，重新导出 agent.runtime 中的 Agent 和客户端。
- notes.md：项目开发笔记和零散记录。
- README.md：项目介绍、技术栈、安装、配置、启动、API 和演示说明。
- requirements.txt：Python 项目依赖及版本列表。

二、agent/：Agent 与会话持久化
- __init__.py：将目录标记为 Python 包。
- agent.py：Agent 主循环；调用大模型、处理工具调用，并提供普通和流式运行逻辑。
- runtime.py：加载模型 API 配置，创建共享 OpenAI 客户端和 Agent 实例。
- session.py：会话消息及会话元数据的数据库读写、创建、查询、改名、清空和删除。

三、api/：API 模型、辅助逻辑和 HTTP 路由
- api_response.py：统一成功和错误响应的数据格式。
- api_schemas.py：聊天、会话和文档请求/响应模型及字段校验。
- chat_helpers.py：聊天流式 SSE 事件封装及最近一轮引用提取。
- session_helpers.py：用户会话命名空间、用户数据库 ID 查询和聊天会话初始化辅助逻辑。
- routes/：按业务域集中定义 FastAPI 路由。
  - __init__.py：将 routes 目录标记为 Python 包。
  - users.py：注册、登录、JWT 刷新和退出登录 HTTP 路由。
  - sessions.py：流式聊天以及会话增删改查 HTTP 路由。
  - documents.py：知识库文档管理 HTTP 路由和请求校验。

四、app/：FastAPI 应用装配和全局处理
- __init__.py：将目录标记为 Python 包并导出 FastAPI 应用。
- main.py：创建 FastAPI 应用、检查启动配置并注册路由。
- errors.py：请求日志中间件及 HTTP、参数校验和未预期异常的统一处理。

五、services/：业务服务逻辑
- __init__.py：将目录标记为 Python 包。
- documents.py：文档解析、原文件/纯文本存储、文档元数据 ORM CRUD 和检索缓存刷新。

六、auth/：认证与用户凭据
- __init__.py：将目录标记为 Python 包。
- jwt_auth.py：注册校验、登录限流、JWT 签发/验证/刷新/撤销和认证审计编排。
- passwords.py：PBKDF2 密码哈希生成及验证。
- repository.py：用户、JWT、登录失败计数和认证审计记录的数据库访问。
- schemas.py：注册、登录、令牌刷新及认证响应的数据模型。

七、modules/：数据库与共享数据结构
- __init__.py：将目录标记为 Python 包。
- database.py：SQLAlchemy 引擎、Session 工厂、表初始化及事务上下文管理。
- document_parser.py：统一解析 PDF、DOCX、XLSX、PPTX、TXT、Markdown、CSV、JSON 和 HTML 为纯文本。
- models.py：SQLAlchemy ORM 模型，包含用户、令牌、会话、认证审计和知识库文档等表结构。

八、tools/：Agent 可调用工具和检索
- __init__.py：将目录标记为 Python 包。
- calculator.py：执行加减乘除计算。
- knowledge.py：加载语料、按用户限制上传文档范围，执行向量与 BM25 混合检索并构造引用证据。
- order.py：订单查询工具示例。
- registry.py：汇总并注册 Agent 可用工具。
- schema.py：从工具函数生成大模型工具调用参数 Schema。
- text_splitter.py：按自然边界切分文本并控制片段长度与重叠。
- weather.py：天气查询工具示例。

九、frontend/：React + TypeScript 前端
- .env.example：前端 API 地址等配置示例。
- index.html：Vite 页面入口 HTML。
- package.json：前端依赖及开发、构建、预览命令。
- package-lock.json：锁定前端依赖版本。
- README.md：前端安装、启动、代理和构建说明。
- tsconfig.json：TypeScript 项目引用配置。
- tsconfig.app.json：浏览器端 TypeScript 编译设置。
- tsconfig.node.json：Vite 等 Node 配置文件的 TypeScript 编译设置。
- vite.config.ts：Vite 插件和开发服务器 API 代理配置。
- src/：React 应用源代码目录。
  - api.ts：封装登录、注册、会话、知识库文档、JWT 自动刷新和 SSE 聊天请求。
  - App.tsx：登录/注册界面、聊天页面、历史会话和知识库文档管理交互。
  - main.tsx：创建 React 根节点并加载应用和样式。
  - styles.css：页面布局、聊天、侧栏、文档面板和响应式样式。
  - vite-env.d.ts：Vite 环境变量和客户端类型声明。
