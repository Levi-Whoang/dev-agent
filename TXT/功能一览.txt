一、根目录文件
- .env：本机运行配置，通常包含数据库、模型 API 和认证密钥；仅供本地使用，不应提交。
- .env.example：环境变量模板，展示启动所需配置项和示例值。
- .gitignore：指定 Git 忽略的密钥文件、数据库、缓存、虚拟环境及前端构建产物。
- .mcp.json：MCP 客户端配置示例；未接入 MCP 时不参与现有聊天流程。
- app.py：兼容启动入口，保留旧的应用导入方式。
- dev_agent.db：本地 SQLite 数据库文件；运行数据文件，不是源码，内容不在本清单中读取。
- main.py：兼容旧导入方式，重新导出 agent.runtime 中的 Agent 和客户端。
- notes.md：项目开发笔记和零散记录。
- README.md：项目介绍、技术栈、安装、配置、启动、API 和演示说明。
- requirements.txt：Python 项目依赖及版本列表。

二、agent/：Agent 与会话持久化
- __init__.py：将目录标记为 Python 包。
- agent.py：Agent 主循环；调用大模型、处理工具调用，并提供普通和流式运行逻辑。
- history.py：历史摘要与上下文 token 预算；保留最近轮次原文、增量合并较早轮次，摘要后台生成不阻塞首包，并在超预算时逐级降级。
- prompt_safety.py：给进入模型的工具输出加不可信边界，持久化保留原始内容。
- control.py：进程内生成任务登记、停止信号、有界工具线程池和工具超时日志。
- stream_filter.py：跨模型分片过滤内部推理标签，输出公开正文。
- runtime.py：加载模型 API 配置，创建共享 OpenAI 客户端和 Agent 实例。
- session.py：会话消息按条追加、历史摘要及会话元数据的数据库读写、旧 JSON 迁移、创建、查询、改名、清空和删除。

三、api/：API 模型、辅助逻辑和 HTTP 路由
- api_response.py：统一成功和错误响应的数据格式。
- api_schemas.py：聊天、会话和文档请求/响应模型及字段校验。
- chat_helpers.py：聊天流式 SSE 事件封装及最近一轮引用提取。
- session_helpers.py：用户会话命名空间、用户数据库 ID 查询和聊天会话初始化辅助逻辑。
- routes/：按业务域集中定义 FastAPI 路由。
  - __init__.py：将 routes 目录标记为 Python 包。
  - users.py：注册、登录、JWT 刷新和退出登录 HTTP 路由。
  - sessions.py：流式聊天以及会话增删改查 HTTP 路由。
  - documents.py：知识库文档管理 HTTP 路由和请求校验。

四、app/：FastAPI 应用装配和全局处理
- __init__.py：将目录标记为 Python 包并导出 FastAPI 应用。
- main.py：创建 FastAPI 应用、检查启动配置并注册路由。
- process_guard.py：启动时检查 worker 配置，多 worker 直接拒绝启动。
- errors.py：请求日志中间件及 HTTP、参数校验和未预期异常的统一处理。
